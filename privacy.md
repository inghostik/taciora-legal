# Privacy Policy - taciora uploader

Last updated: November 16, 2026

## Data we access

With the account owner's permission, the app uses the TikTok scopes user.info.basic (to show which account is connected), video.upload and video.publish (to post the owner's own videos).

## How data is stored

Access tokens are stored only on the owner's personal computer. No data is sold, shared with third parties, or used for advertising. The app has no other users and collects no data about other TikTok users.

## Revoking access

Access can be revoked at any time in TikTok: Settings, Security, Manage app permissions. Deleting the local token file removes all stored data.
